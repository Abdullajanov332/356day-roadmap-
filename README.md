# Cybersecurity 365-Day Roadmap

A structured **365-day cybersecurity learning and practice roadmap** designed to build practical skills from foundational concepts to advanced penetration testing, red teaming, cloud security, binary exploitation, bug bounty, and certification preparation.

## 📚 Roadmap

This roadmap covers 12 months of structured cybersecurity learning:

* Month 1: Cybersecurity Foundations
* Month 2: Web Security
* Month 3: Network Pentesting & Active Directory
* Month 4: Bug Bounty & Reconnaissance
* Month 5: eJPT & CPTS Preparation
* Month 6: Cloud Security
* Month 7: Binary Exploitation
* Month 8: Red Teaming
* Month 9: Intensive Bug Bounty & Portfolio
* Month 10: Big Tech Security Preparation
* Month 11: OSCP Preparation
* Month 12: Certifications & Job Search

## 🎯 Daily System

The roadmap follows a simple daily structure:

* 40% Theory
* 40% Practical Labs
* 20% Notes & Writing

Each day should also include a GitHub `Day-N` commit to track progress.
